AI 托管聊天机器人 · 使用手册
========================================

这份手册是给“完全不想碰代码”的人写的。照着一步步点，就能跑起来。


零、先说清楚三件事
------------------
1. 这套东西不是一个聊天机器人，是“账号代驾”：它挂在你自己的 Telegram 账号上，
   用那个账号的身份，替你回消息。
2. 它必须运行在一台一直开着的机器上（云服务器最好）。你电脑关机了就没人替你回。
3. 用你自己的账号之前，有两样东西必须先填，否则它一个字都回不出来：
   · Telegram 的 api_id / api_hash（免费，1 分钟拿到）
   · 一个大模型的 Key（OpenAI / DeepSeek 这类，按用量花钱）
   这两样我没法替你填——它们绑的是你的账号和你的钱。


一、打开后台
------------
后台就是一个网页：左边一排菜单（总览 / 账户 / 人设 / 会话 / 联系人 / 主动任务 /
风格档案 / 语音 / 日志 / 系统设置），右边是内容。

登录账号：admin
登录密码：Zaka2026!Op
（第一次进去请到「系统设置」改掉它，并打开两步验证。）


二、第一步：填模型（不填就回不了话）
------------------------------------
点左边「系统设置」→ 模型设置：
  接口地址（base_url）：填服务商给的地址，例如
       OpenAI：        https://api.openai.com/v1
       DeepSeek：      https://api.deepseek.com/v1
  模型名：例如 gpt-4o-mini 或 deepseek-chat
  API Key：粘贴你的 Key
  然后点「测试连通」，显示成功就对了。

同一页往下还有「控制 bot」：token 已经预置好了（就是你给我的那个），
你把 api_id / api_hash 填上之后重启一次，它就会自己上线，
之后你在 Telegram 里给这个 bot 发 /status、/stop、/skip @某人 就能远程控制。


三、第二步：拿 Telegram 的 api_id / api_hash（免费）
--------------------------------------------------
1. 电脑浏览器打开 https://my.telegram.org
2. 输入你的手机号（带国家码，比如 +855...），收验证码登录
3. 点「API development tools」
4. 随便填个应用名（比如 my-app）、平台选 Other，提交
5. 页面上会出现 api_id（一串数字）和 api_hash（一串字母数字）
6. 把这两个复制下来

注意：这一步必须用你自己的手机号登录，别人代拿的没用。
拿到之后可以填在「系统设置」里（对所有账号生效），
也可以绑号时单独填（一个号一套）。


四、第三步：绑号（先绑 1 个，跑顺了再绑第二个）
--------------------------------------------
点左边「账户管理」→ 添加账号：
  备注名：随便，比如「主号」
  手机号：+85512345678 这种格式，带国家码
  api_id / api_hash：上一步拿到的
  代理：有就填，没有留空（你在柬埔寨本地，一般不用）
点保存 → 点这个账号的「登录」→ 它会把验证码发到你的 Telegram App 里
（不是短信，是 Telegram 官方那个服务号给你发的消息）→ 把收到的 5 位数字填进去。
如果你开了两步验证，接着会让你输密码。

登录成功后状态会变成「在线」，会话加密保存在服务器上，重启不用重新登录。

⚠️ 一个号一个出口 IP。你绑两个号，最好两个号走不同网络，别在同一台机器同一个 IP
上同时挂一堆号，那是被封得最快的方式。


五、第四步：受人设 + 绑到账号
----------------------------
点「人设管理」，里面已经预置了 12 个人设模板（不同性别、年龄、职业、性格）。
每个模板都能改：姓名、性别、年龄、职业、城市时区、性格关键词、语气档位、
口头禅、emoji 习惯、句长偏好、分段习惯、禁忌话题、默认语言、音色、语音发送比例。

改完点保存 → 回到「账户管理」，把这个账号的人设选成你刚建的那个。

想验证人设有没有生效：同一条消息，用三个人设各回一次，语气应该明显不一样。


六、第五步：试第一条对话
------------------------
拿你另一个 Telegram 号（或者让朋友）给这个号发一句：
「在忙吗」
正常应该发生的事：
  · 不会秒回，先有一段“正在输入”
  · 回 1-3 条，不是一大段
  · 语气像你设的那个人设

没回？按这个顺序查：
  1. 账户管理里，这个号的「AI 开关」和「自动回复」是不是开着的
  2. 系统设置里模型测试连通有没有成功
  3. 日志与用量里看最近一条错误（最常见的两个：模型 Key 错、余额不足）
  4. 会话列表里点开这个联系人，看是不是被设成了「暂停」或人工接管中


七、语音条
----------
「语音管理」里，每个性别有 4 个以上音色，点一下就能试听。
人设里有个「语音发送比例」，设成 30 就是三成消息用语音回。

觉得音色不像本人：用「克隆」上传 30 秒到 3 分钟本人说话的录音，
它会把音色做成一个可选音色。注意：中文克隆效果好，高棉语、越南语跨语种会跑味，
这是行业现状，不是这版的问题。

收到对方发来的语音条，它会自动转成文字再理解，不会听不懂。


八、主动任务（最容易封号的一步，别急着用）
----------------------------------------
「主动任务」里可以勾选联系人、按标签或最后互动时间筛、设每天发几个人、
什么时段发、间隔多久。开场白是按人设和对方画像生成的，同一批不会重复。

但请记住：新号前 36 小时只做被动回复，不要主动找人。
然后首周每天主动私聊个位数，慢慢加。这套系统里已经内置了静默期和三级限速
（每分钟 6 条 / 每小时 40 条 / 每天 150 条，后台可调，默认是保守值），
不要为了“快”把它们调大——那不是效率问题，是账号能不能活过一周的问题。


九、随时急停（三处都能停）
--------------------------
1. 总览页右上角「一键全停」
2. 账户管理里单个账号的开关
3. 会话详情页里对单个联系人的「暂停」
另外：你自己在手机上手动回了一句，AI 会自动让路 20 分钟（总览里可改时长），
不会跟你抢着说话。

远程控制：给你的控制 bot 发
  /status            看各账号状态
  /stop              全部停发
  /resume            全部恢复
  /skip @某人        今天别回这个人
  /takeover @某人    人工接管 2 小时


十、常见问题
------------
Q：登录时收不到验证码？
A：Telegram 现在不发短信，验证码是 Telegram 官方服务号发到你 App 里的消息。
   如果是全新号第一次登，可能会让你先走邮箱验证，按提示走完再回来登。

Q：提示 FloodWait / 等待几百秒？
A：这是 Telegram 的限流，系统会精确等待，别手动反复重试——越点越久。

Q：AI 回得很慢或者不回？
A：先看模型测试连通，再看日志与用量里的错误记录。模型接口超时是主要原因。

Q：会不会被封？
A：会。任何自动化接管都有风险。降低风险的做法：一账号一 IP、前 36 小时只被动回、
   别群发、别秒回、别在凌晨狂发。这套系统把这些都做成了默认行为，你只要别去关它。

Q：数据存哪？
A：都在你自己的服务器上。会话文件是加密存的，后台有操作审计日志，
   谁在什么时候对谁发了什么、依据是什么，都能查到。


十一、换台机器部署（如果你想搬走）
----------------------------------
包里有一键部署工程：
  1. 装好 Docker
  2. 把包里 .env.example 复制成 .env，填密码、模型、api 凭据
  3. docker compose up -d --build
  4. 浏览器打开 http://你的服务器IP
数据库、缓存、后台、语音全都在里面，不需要额外装东西。

如果你不想自己弄，把服务器的 IP 和登录账号密码发我，我直接给你装好。
